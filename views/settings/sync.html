AniList Triple Sync

Copies your list (the source) to a second AniList account and to MyAnimeList, for anime and manga. After the first run, only titles that changed are sent.

Never synced.


    

  

  

    Problems
    

    

  


  
Settings

  
Everything below is saved on this device as you change it.


  
Source

  

    
    
  


  
Target AniList account

  

    
Not connected.

    
Make your own API client at anilist.co/settings/developer and set its Redirect URL to https://anilist.co/api/v2/oauth/pin. Log in with the account you want to copy to.

    
    
    
    
    
    
    
    
    
  


  
MyAnimeList account

  

    
Not connected.

    
Make your own API app at myanimelist.net/apiconfig and give it a Redirect URL (for example http://localhost). Type the same one below.

    
    
    
    
    
    
    
    
    
    
    
  


  
Discord (optional)

  

    
Three webhooks, each optional. They are links you make in Discord (channel settings > Integrations > Webhooks). Forum channels work: the cards are sorted into threads.

    Log report
    
A short summary of each sync: counts and problems.

    
    
    
    
    
    
    Update cards
    
One card for each title whose progress goes up, with its details and poster. It works even if no target account is connected. The first sync only remembers your progress and posts nothing.

    
    
    
    
    
    
    
    
    
A title goes to the thread of its first custom list if that list is named here (for example [ANIME] Iseki). Everything else goes to [ANIME] General Updates.

    
    
    
    
A list is themed when its name contains Isekai, Iseki, Tensei, Rom Com or Romantic Comedy (and it has its own thread above). Test cards go to General Updates, so your list threads stay clean.

  


  
Options

  

    
    
    
    
    
    
    
    
    
    
    
Your client secrets, login tokens and webhook link are stored only on this device. Resetting memory makes the next sync ask how to start again. A long sync only runs while the app is open, so the screen is kept awake during it.
